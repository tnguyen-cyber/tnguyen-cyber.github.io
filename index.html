Network Infrastructure · Security

Enterprise Network Architecture & Security

Problem:Business had a flat, unsegmented network with no remote access, no threat detection, and no access controls between devices.

Designed and deployed a fully segmented enterprise network on Ubiquiti UniFi hardware from the ground up. Implemented VLAN isolation, dual-tier VPN access, a layered firewall ruleset, and active intrusion prevention — replacing an undifferentiated network with a zero-trust-adjacent architecture.

  • Deployed Ubiquiti UDM Pro as core router and controller, connected to a Comcast Business fiber uplink with provisioned static IP
  • Designed 4-VLAN network: Core (VLAN 1), Staff (VLAN 20), Security (VLAN 30), IoT (VLAN 40) — isolating untrusted devices from operations
  • Implemented two WireGuard VPN servers: Admin VPN (full LAN access) and Remote VPN (scoped access), with separate firewall enforcement for each tier
  • Wrote 15 custom firewall rules using named network objects — blocking VPN clients from Staff VLAN and NAS by default, restricting Worker VPN to Google Workspace IPs on HTTPS only
  • Enabled UniFi CyberSecure IPS (Proofpoint + Cloudflare) with 70,955 active signatures across 6 threat categories: botnets, malware, exploits, P2P/dark web, reconnaissance, and protocol vulnerabilities
  • Staged staff VPN firewall rules in disabled state for clean future activation — no reconfiguration required at rollout

Provisioned and configured a Synology NAS as the organization's central file server and media database. Migrated a full employee mailbox archive into the NAS. Implemented a dedicated firewall profile on the NAS itself as a second layer of access control beyond the network perimeter.

  • Configured Synology DSM: shared folders, user/group permissions, file services (rsync, NTP, NFS), and remote access via Synology Drive
  • Migrated a complete employee email archive (100+ export files) into NAS-hosted storage as part of a formal offboarding procedure

  • Staged staff VPN rule pre-written in disabled state, ready to activate when staff VPN is provisioned

Automation · Web Dev · API Integration

Shopify CDN Media Pipeline

Problem:Shopify storage was completely full — the business could not create new product listings. Videos hosted on Shopify were consuming all available storage.

Designed and built a complete 6-stage media automation pipeline in PowerShell to migrate product videos from Shopify-hosted storage to Cloudflare R2, freeing storage capacity and unblocking new product creation. Registered and configured a custom Shopify Admin API app with precisely scoped permissions. Migrated 1,815 products to CDN-hosted video in production. Extended the Shopify theme with custom Liquid and CSS to display CDN-hosted videos with full backward compatibility for legacy Shopify-hosted content.

  • Custom Shopify App: Registered a private Admin API app (Product & Media Automation) with precisely scoped OAuth permissions — read/write_products, read/write_inventory, read/write_metaobjects, read/write_product_listings, read/write_files — using API version 2026-01
  • Stage 1 — Organize: CSV-driven script pairs raw camera files (JPG + video) to product SKUs and creates a standardized folder structure per SKU, with dry-run mode
  • Stage 2 — Normalize: ffmpeg pipeline converts .MOV files to web-optimized .MP4 with faststart flag for streaming performance
  • Stage 3 — Upload: Pushes organized media to Cloudflare R2 via AWS S3-compatible CLI; skips existing SKUs idempotently; timestamped logs
  • Stage 4 — Auth: Built a local OAuth 2.0 callback server using System.Net.HttpListener in PowerShell — no dependencies — to capture and exchange Shopify authorization codes
  • Stage 5 — Create Drafts: Calls Shopify Admin REST API to create draft product listings from CSV; validates all fields (title, description, weight with unit conversion, tags); stores CDN URL as a custom product metafield (custom.external_video_url)
  • Stage 6 — Validate & Fix: Post-creation auditor queries Shopify API for every SKU, checks all required fields, detects stale Shopify-hosted videos and queues deletion, verifies CDN metafield URL matches SKU
  • Modified Shopify theme Liquid templates with conditional rendering: CDN video displays for migrated products; Shopify-hosted video displays for legacy listings — zero broken products during migration
  • Result: 1,815 product videos migrated to cdn.opaltrove.com; Shopify storage freed; new product creation unblocked

Cybersecurity · Identity Management

Identity, Access & Credential Security

Problem:Employees were sharing login credentials across social media platforms with no MFA, no individual accountability, and no way to revoke access when someone left.

Identified shared credential usage as a critical security risk and systematically addressed it across every business platform — deploying hardware security keys, implementing centralized password management, and migrating social platforms to individual role-scoped employee accounts.

  • Deployed Yubico YubiKey hardware security keys (FIDO2/WebAuthn) organization-wide as phishing-resistant MFA — the strongest available authentication factor, recommended by NIST and CIS Controls
  • Implemented centralized password management to eliminate shared, weak, and reused credentials across the organization
  • Identified shared social media logins as a security and accountability gap; migrated Facebook and Instagram to Meta Business Suite with individual employee accounts and role-scoped permissions
  • Audited all business platforms for access control maturity: leveraged native employee/seller login structures on Shopify and WhatNot; TikTok individual account migration in progress
  • Combined with Google Workspace IAM, offboarding procedures, and VPN access tiering — established a complete identity lifecycle covering provisioning, access scoping, MFA enforcement, and revocation
